# Security Policy

## Reporting

Report suspected vulnerabilities privately through GitHub Security Advisories when enabled. Do not include API keys, financial records, private diligence materials, credentials or customer data in public issues.

Include the affected version/component, reproduction steps, impact and a sanitized proof of concept.

## Data and model boundaries

OpenGravity produces analytical estimates and decision-support outputs. A probability or score is not a guarantee, investment recommendation or substitute for independent due diligence. Treat uploaded financial data, evidence sources and model outputs as confidential unless explicitly configured otherwise.

Keep provider credentials server-side, validate imported data, record provenance for external evidence and avoid logging raw sensitive inputs. Agent-generated claims should remain traceable to evidence and uncertainty.
