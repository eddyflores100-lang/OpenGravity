Metodología

Cuatro capas, cero cajas negras

Todo el pipeline está documentado en el repo: desde el Monolito de la Verdad V9.7.1 que calibró los coeficientes hasta los reportes de Brier score. Esto es lo que corre bajo el capó.

1 · Prior bayesiano

El motor parte de una creencia previa (P = 20%) y la ajusta con unit economics: LTV/CAC, runway y crecimiento mes a mes, con interacción LTV×crecimiento y penalización por burn desenfrenado.

logit = −1.386 + 0.70·LTV + 2.50·log(1+g) + 0.50·log(R/12) + 3.0·LTV·g − burn − 1.8

2 · Señales agénticas

Agentes de investigación (DeerFlow, MiroFish) devuelven hallazgos con evidencia y credibilidad. Cada señal empuja el logit directamente — un hallazgo crítico puede tumbar métricas espectaculares, como en WeWork.

logit_final = logit_base + Σ impactos_agénticos

3 · Monte Carlo

Se perturban las métricas con ruido gaussiano (±15–25%) y se re-puntúan 1.500 escenarios. El resultado no es un número mágico: es una distribución completa con percentiles P10/P50/P90 y tasa de veredictos.

P(Hit)ᵢ = σ(logit(métricas + εᵢ))  ×  1.500 iteraciones

4 · Calibración honesta

El modelo se calibró contra datasets con ground truth y se validó fuera de distribución (reportes de Brier score en el repo). Datos auditados → IC ±5%; datos inferidos → IC ±15%. La incertidumbre se declara, no se esconde.

IC = P(Hit) ± 0.05 (auditado) | ± 0.15 (inferido)

Arquitectura

Tres servicios, despliegue en un comando

Docker Compose levanta todo el stack con healthchecks. Los agentes externos reportan hallazgos de vuelta al Oracle mediante /callback/agent-report/{id} — el loop agéntico se cierra solo.

:8000

Oracle

FastAPI · Python 3.12

La API del motor: POST /evaluate recibe métricas y devuelve P(Hit), IC, logit y riesgo de down round. Almacenamiento acotado, CORS configurable y endpoint de callback para agentes.

:3001

Core Bot

grammY · TypeScript

Reconocimiento vía Telegram con enrutador LLM multi-proveedor (Mistral / Moonshot / Gemini) y failover secuencial. Storage con motor de queries real: where, orderBy y limit que sí ejecutan.

:3000

Dashboard

Next.js · Tailwind

Panel institucional para revisar evaluaciones, intervalos de confianza y señales agénticas con su evidencia enlazada. Esta misma página es una demostración del estilo del producto.

telegram→core bot→oracle→P(Hit)→agentes investigan→callback con evidencia
